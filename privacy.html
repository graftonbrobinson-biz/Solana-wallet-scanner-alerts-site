Privacy Policy

Last updated: October 29, 2026 · Applies to Solana Wallet Scanner Alerts and this website.

Who operates this program

This SMS alert program and this website are operated under the approved A2P 10DLC brand Solana Wallet Scanner. Contact: graftonbrobinson@gmail.com.

What information is collected

CategorySourcePurpose
Watched wallet addresses Chosen manually by the operator Identify which public on-chain activity to monitor
On-chain swap/transaction data Public Solana blockchain data (Helius RPC) Detect buy/sell confluence signals
The recipient's phone number Provided directly by the recipient (the operator) Deliver SMS alerts via Twilio
Message content and delivery status Generated by the application; delivery status reported by Twilio Record what was sent and whether it was delivered

This program does not collect information about the public. It does not have a sign-up form, does not run advertising or marketing campaigns, and does not purchase or receive contact lists from any third party.

Where information is stored

All of the information above is stored locally, in a database on the operator's own computer. It is not hosted on a public server, not accessible over the internet, and not shared with anyone other than the service providers listed below, to the extent strictly necessary to operate the program.

Third-party service providers

  • Twilio — sends the SMS alerts. Twilio receives the recipient's phone number and the message text in order to deliver each message. See Twilio's own privacy policy.
  • Helius (Solana RPC provider) — supplies public blockchain data used to detect wallet activity. No phone numbers or personal information are sent to this provider.

Data retention

The application's source code was inspected to write this section accurately, rather than stating an assumed retention period. It contains no automatic deletion, expiration, or retention-limiting logic of any kind. Watched wallet addresses, on-chain swap records, alert records, and SMS delivery logs are all kept indefinitely in a local database on the operator's own computer, and are only removed if the operator manually deletes them. There is currently no scheduled or automatic process that erases this data after any fixed period.

Mobile information sharing — required disclosure

No mobile information will be shared with third parties or affiliates for marketing or promotional purposes. All the above categories exclude text messaging originator opt-in data and consent; this information will not be shared with any third parties.

This is the exact clause CTIA's Messaging Principles and Best Practices require, as documented by Twilio for A2P 10DLC campaign registration. It is deliberately left unqualified — it does not stop Solana Wallet Scanner from using a vendor needed to run this program itself (for example, Twilio, which this policy already names above as the platform used to send these messages); it specifically means opt-in/consent data is never shared with anyone else for marketing or promotional purposes. Confirm the current exact wording required at the time of submission, since carrier and platform requirements can change.

Your choices

Reply STOP to stop receiving messages, or contact graftonbrobinson@gmail.com at any time to ask what information is held and to request its deletion. See the SMS Opt-In page for a full explanation of how opt-out is currently handled for this program.

Changes to this policy

If this policy changes, the updated version will be posted on this page with a new "Last updated" date above.
